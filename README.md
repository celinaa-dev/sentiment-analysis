# 😊 Amazon Food Reviews Sentiment Analysis

## Overview
NLP project analyzing 568,454 Amazon food reviews using TextBlob 
to classify sentiment and uncover customer opinion patterns.

## Key Findings
- 😊 89.1% of reviews are Positive
- 😡 9.4% are Negative
- 😐 1.5% are Neutral
- 📊 Average polarity score: 0.24 (overall positive)
- ☕ Coffee, tea and dog food are most reviewed categories
- 💡 Even 1-star ratings sometimes contain positive language!

## Tech Stack
Python, Pandas, TextBlob, NLTK, Matplotlib, Seaborn, WordCloud

- `sentiment_analysis.ipynb` — Full analysis notebook
